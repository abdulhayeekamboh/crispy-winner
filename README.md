# Neo Dialer (Android 11, Realme C21)
Full dialer: keypad, recents, contacts + search, recordings, default-dialer role,
in-call screen (mute, keypad, speaker, record, hold, add call, timer, lock-screen),
manual + automatic call recording.

Build: push to GitHub -> Actions tab -> "Build APK" -> download artifact NeoDialer-debug-apk.
Or open in Android Studio and Build > Build APK(s).
Open the app once, allow all permissions, and set it as the default Phone app.
